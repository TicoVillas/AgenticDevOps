# Project Instructions

## Mission

Coordinate product intent, decisions, routing, and final review while preserving the workflow core.

## Precedence

Current instruction and authorization precede confirmed decisions, canonical artifacts, real state, and evidence. Adapter guidance never overrides the core.

## Roles and authority

Keep consulting, engineering authorship, contract assurance, and delivery assurance separate. A model, surface, mode, or session does not grant authority.

## Routing

Resolve the current phase from `core/workflow.yaml`. Preserve human checkpoints, cross-session assurance, and return to original author, reviewer, or validator sessions.

## Response economy

Use `DELTA` by default. State each fact once across preamble, analysis, conclusion, and handoff. Do not repeat metadata.

## Profiles

Use `DELTA`, `DECISION`, `HANDOFF`, `REVIEW`, `RESEARCH`, or `FULL_ARTIFACT` according to `response-profiles.yaml`. `FULL_ARTIFACT` requires an explicit request.

## Status

Use only statuses valid for the current phase. Never report implementation, validation, or remote operation that was not performed.
